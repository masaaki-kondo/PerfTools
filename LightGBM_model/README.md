# LightGBM AI Inference Model - User Guide

This directory contains the standalone, fully trained AI model pipeline for predicting GPU performance across different architectures. It takes raw Nsight Compute (NCU) profiling metrics from a source GPU (e.g. A100) and predicts the execution time and stall breakdowns on a target GPU (e.g. H100).

## Repository Structure & GitHub Upload

When uploading this package to GitHub or deploying it, **only the core logic and models** need to be committed. Several files and directories are generated automatically at runtime.

### Core Files (Must be uploaded to GitHub)
```text
gpu_perf_analysis/
├── data/
│   └── gpu_microarch_specs.csv    <-- REQUIRED: Exact path must be `../data/gpu_microarch_specs.csv` relative to LightGBM_model/
├── LightGBM_model/
│   ├── README.md                  <-- This user guide
│   ├── extract_features.py        <-- Script to parse NCU raw files and hardware specs
│   └── AI_model/
│       ├── run_inference.py       <-- Main CLI entry point for the frontend
│       └── model/                 <-- Directory containing pre-trained LightGBM weight files (.txt) and .pkl mappings
```

### Runtime Generated Files (Do NOT upload / Mark as gitignore)
```text
LightGBM_model/
├── __pycache__/                   <-- Automatically generated Python bytecode cache
├── config.yaml                    <-- Example: Automatically generated/updated configuration file
├── extracted_features.csv         <-- Example: Intermediate Feature Matrix generated during inference
└── predictions/                   <-- Example: Directory where final prediction CSVs and logs are saved
```

## File Explanations

1. **`AI_model/run_inference.py`**: The main executable script. It handles argument parsing, calls the extraction pipeline, loads the trained LightGBM models, makes predictions, and outputs the final CSV.
2. **`extract_features.py`**: Reads raw NCU files and `gpu_microarch_specs.csv`. It calculates hardware ratios (Target vs Source) and derives the complex `I-*` (Input) features needed by the model. 
3. **`extracted_features.csv`**: This is an intermediate file generated by the tool. It contains the metadata (`src_gpu`, `tgt_gpu`, `kernel_name`) and all the `I-*` input features (NCU raw metrics + hardware ratios). It **does not** contain any ground truth (`S-`) or output (`O-`) columns. It represents exactly what the AI model sees during inference.
4. **`AI_model/model/*.txt`**: These are the fully trained physical weight files for the 7 predicted targets. They are loaded instantly during inference without any need for re-training.
5. **`config.yaml`**: A simple YAML file that gets automatically updated with your CLI arguments for logging and reference purposes.

## Environment Requirements

To run this model on any machine, you must have the appropriate Python environment set up.

1. **Python Version**: Python 3.8 or higher is recommended.
2. **Required Packages**:
   Install the following dependencies using pip:
   ```bash
   pip install pandas numpy lightgbm pyyaml
   ```
   *(Note: No GPU-specific libraries like CUDA or PyTorch are required because LightGBM inference runs completely on the CPU.)*

## How to Run Inference

As a user, you only need to run a **single command**. 

Ensure you are running the command from inside the `LightGBM_model` directory:

```bash
python AI_model/run_inference.py \
    --src_gpu=A100 \
    --tgt_gpu=H100 \
    --ncu_csv=/path/to/your/ncu_raw_files_directory \
    --out=predictions/prediction.csv \
    --log=predictions/report.txt
```

### Command Line Arguments:
> **All arguments below are REQUIRED.** If you omit any of them, the script will automatically halt and print a helpful error message explaining which parameter is missing.

- `--src_gpu`: The architecture the NCU files were profiled on. **(Must be one of: `A100`, `H100`, `GB200`)**
- `--tgt_gpu`: The target architecture you want to predict performance for. **(Must be one of: `A100`, `H100`, `GB200`)**
> *Note: The model is strictly trained on A100, H100, and GB200 hardware. Providing other GPUs will result in an error.*
- `--ncu_csv`: Absolute or relative path to the folder containing the `.csv` files exported from Nsight Compute for the Source GPU.
- `--out`: Where to save the final predicted CSV containing the `O-*` predictions.
- `--log`: Where to save a simple text summary report of the predictions.

### What Happens When You Run This?
1. The script reads the NCU files from your provided directory.
2. It fetches the hardware specs for `A100` and `H100` from `../data/gpu_microarch_specs.csv`.
3. It constructs the `extracted_features.csv` matrix.
4. It loads the 7 pre-trained models from `AI_model/model/`.
5. It predicts execution time, occupancy, throughput, and stall breakdowns, saving them directly to `predictions/prediction.csv`.
